The Joy of Building (Functional) Languages
==========================================

This is the repository for my keynote presentation at the 2024 Haskell
Symposium, containing my slides as well as example code.

A video of the talk can be found on YouTube:
https://www.youtube.com/watch?v=C8PcRqIToCM Unfortunately it seems
that the video did not record properly for the first half of the talk
or so, but the audio is fine, so you can follow along with the
[slides](https://github.com/byorgey/HS24-keynote/blob/main/HS24-keynote.pdf)
yourself.
